# 小規模事業者持続化補助金 ヒアリングフォーム

PC・スマートフォン・タブレットから利用できる、持続化補助金の事業者向けヒアリングフォームです。
Claudeアカウント等のログインは不要で、リンクを開くだけでどなたでもご利用いただけます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 一般型・創業型を選ぶトップページ |
| `ippan.html` | 持続化補助金＜一般型＞ヒアリング（全8ブロック・約123問） |
| `sogyo.html` | 持続化補助金＜創業型＞ヒアリング（全8ブロック・約148問） |

## 使い方

GitHub Pagesで公開後、`index.html` のURLを事業者様に共有してください。
回答内容は各自の端末（ブラウザのlocalStorage）に一時保存され、最終確認画面から
CSVまたはテキストファイルとして保存・コピーできます。サーバーには一切送信されません。

## 更新方法

元になるExcelシート（`小規模事業者持続化補助金_ヒアリングシート_入力フォーム.xlsx` 等）を
更新した場合は、対応するHTMLファイル内の `BLOCKS` 定数（設問データ）を書き換えて
コミット・pushしてください。GitHub Pagesは自動的に最新版を配信します。
